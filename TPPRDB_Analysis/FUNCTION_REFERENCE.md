# `util_functions.py` Function Reference

This reference covers every function defined in `util_functions.py`, including
private helpers and functions nested inside other functions. Nested helper
entries are identified by their containing function. A leading underscore
indicates an internal helper; it does not by itself determine whether a name is
included in the module's `__all__`.

| Function | Arguments | What it does |
|---|---|---|
| `get_names(val: Any, col: str)` | `val`: value or stringified Python literal; `col`: dictionary key | Extracts matching values from a dictionary or list of dictionaries; returns unparseable strings and other input types unchanged. |
| `combine_group_rows(df: pd.DataFrame, group_cols: list[str])` | `df`: source DataFrame; `group_cols`: grouping columns | Groups rows and aggregates each other column from distinct non-null values, joining multiple values with `"; "`. |
| `combine_group_rows.combine_series(series)` *(nested)* | `series`: one grouped column | Returns `pd.NA` for no values, the sole value when unique, or the unique values joined by `"; "`. |
| `preprocess_string_columns(df: pd.DataFrame)` | `df`: DataFrame to normalize | Modifies object columns in place by uppercasing and trimming strings, and converts common textual null markers to `pd.NA`. |
| `_extract_range(x: Any)` | `x`: mapping, list, tuple, string, or other value | Extracts a range from a mapping's `"range"` value or a numeric range in text; joins list/tuple parts with hyphens and otherwise returns cleaned text or `None`. |
| `preprocess(text: Any, stopwords: list[Any] \| None)` | `text`: input text; `stopwords`: optional words to exclude | Lowercases text, keeps alphabetic words of at least three characters, removes stopwords, and joins the remainder. Non-string input returns an empty string. |
| `_join_non_na(row)` | `row`: pandas Series | Trims and joins non-null, non-empty values other than textual `nan`, `none`, or `na`; returns `pd.NA` if none remain. |
| `_prepare_vectorizer_corpus(docs: list[str], vectorizer_model)` | `docs`: source documents; `vectorizer_model`: fitted-capable vectorizer | Fits the vectorizer, tokenizes documents, and creates a Gensim dictionary and bag-of-words corpus. Returns `(tokenizer, tokens, dictionary, corpus)`. |
| `_get_topic_words(topic_model, exclude_outliers: bool = True)` | `topic_model`: fitted BERTopic-compatible model; `exclude_outliers`: whether to omit topic `-1` | Flattens topic words into a list, preserving topic order and repeated words. |
| `calculate_topic_diversity_mtld(topic_model, min_words: int = 10)` | `topic_model`: fitted BERTopic-compatible model; `min_words`: minimum word-count threshold | Calculates MTLD across topic words, returning `0.0` when there are too few words or calculation fails. |
| `_compute_silhouette_score(embeddings, topics)` | `embeddings`: document vectors; `topics`: assignments with `-1` for outliers | Computes silhouette score for non-outlier documents; returns `-1.0` when the score is not applicable or fails. |
| `_create_bertopic_model(vectorizer_model, embedding_model=None, candidate_topics=None, nr_topics=None, min_topic_size=2, random_state=38, calculate_probabilities=False)` | `vectorizer_model`: BERTopic vectorizer; `embedding_model`: optional embedding model; `candidate_topics`: optional zero-shot labels; `nr_topics`: target topic count; `min_topic_size`: minimum topic size; `random_state`: UMAP seed; `calculate_probabilities`: probability-calculation option | Creates an unfitted BERTopic model using the project's UMAP and zero-shot configuration (minimum similarity `0.8`). |
| `_outlier_ratio(topics)` | `topics`: topic assignments | Returns the proportion of assignments labeled `-1`, `-1.0`, or `"unknown"`; returns `0.0` for empty input. |
| `_count_valid_topics(topics)` | `topics`: topic assignments | Counts distinct labels other than `-1`, `-1.0`, and `"unknown"`. |
| `calculate_coherence_score(topic_model, dictionary=None, corpus=None, tokens=None)` | `topic_model`: model exposing topic methods; `dictionary`: Gensim dictionary; `corpus`: optional bag-of-words corpus; `tokens`: tokenized documents | Calculates Gensim normalized PMI (`c_npmi`) coherence from topic words found in the dictionary. Returns `0.0` when required data, usable topics, or a successful calculation is unavailable. |
| `calculate_diversity_score(topic_model)` | `topic_model`: model exposing `get_topics()` | Computes the number of unique topic words divided by the square root of total topic-word assignments. |
| `resolve_overlaps(positions, markers, min_dist, steps=40, repulsion_strength=1.0, marker_repulsion_strength=2.0, attraction_strength=0.05, max_step=0.5)` | `positions`: `(N, 2)` label coordinates; `markers`: `(N, 2)` anchors; `min_dist`: repulsion threshold; `steps`: iterations; `repulsion_strength`: label repulsion multiplier; `marker_repulsion_strength`: marker repulsion multiplier; `attraction_strength`: anchor attraction multiplier; `max_step`: per-coordinate movement limit | Iteratively adjusts label coordinates with repulsion and attraction forces, returning a new floating-point array. |
| `float_range(start, stop, step)` | `start`: first value; `stop`: exclusive bound; `step`: increment | Yields successive values while the current value is less than `stop`. |
| `find_and_replace(df, findColumn, replaceColumn, conditions, choices)` | `df`: DataFrame modified in place; `findColumn`: unused legacy argument; `replaceColumn`: destination column; `conditions`: boolean conditions for `numpy.select`; `choices`: corresponding replacement values | Assigns selected values only where the destination column equals an empty string, using `"NA"` as the default. |
| `fill_missing_values(df, primary_cols, alternate_cols)` | `df`: DataFrame modified in place; `primary_cols`: columns to fill; `alternate_cols`: corresponding source columns | Fills nulls in each primary column from its alternate and then drops that alternate column. Pairs columns with `zip`. |
| `run_model(docs, embeddings, vectorizer_model, notopics, clustermodel=None, embedding_model=None, candidate_topics=None)` | `docs`: documents; `embeddings`: aligned vectors; `vectorizer_model`: vectorizer; `notopics`: requested topic count; `clustermodel`: unused legacy argument; `embedding_model`: optional embedding model; `candidate_topics`: optional zero-shot labels | Fits BERTopic, computes coherence, MTLD diversity, silhouette, and a weighted score (`0.70`, `0.15`, `0.15`), then returns the metrics and model. |
| `cross_validate_zeroshot_bertopic(docs: list[str], embeddings: np.ndarray = None, vectorizer_model=None, embedding_model: object = None, topic_list: list[str] = None)` | `docs`: documents; `embeddings`: aligned vectors; `vectorizer_model`: vectorizer; `embedding_model`: optional embedding model; `topic_list`: zero-shot labels | Fits 25 repeated training folds and summarizes outlier ratio, topic count, and c-TF-IDF structural stability. Fold scores are calculated on training subsets; held-out indices are not used. |
| `rename_key(item, key_mapping)` | `item`: value containing a serialized mapping; `key_mapping`: old-to-new key mapping | Renames keys in a serialized string and parses it with `ast.literal_eval` when possible; otherwise returns the cleaned string or unchanged non-string/empty values. |
| `lib_to_dict(entry: Entry)` | `entry`: bibtexparser entry with key, type, and fields | Converts a bibtexparser entry to a dictionary containing `ID`, `ENTRYTYPE`, and its fields. |
| `convert_fields(data: pd.Series)` | `data`: Series of bibtexparser field objects or other values | Returns each field's value, using `pd.NA` for elements that are not bibtexparser `Field` instances. |
| `remove_duplicate_dicts(input_data: list[dict])` | `input_data`: nested lists containing dictionaries | Recursively flattens nested lists, ignores non-dictionaries, and removes duplicate dictionaries while preserving first-occurrence order. |
| `remove_duplicate_dicts.flatten(items)` *(nested)* | `items`: nested lists and values | Collects dictionaries recursively into the enclosing function's flat list. |
| `remove_duplicate_dicts.make_hashable(obj)` *(nested)* | `obj`: dictionary, list, tuple, or scalar | Recursively converts dictionaries, lists, and tuples to hashable structures for deduplication. |
| `separate_author_initials(authors)` | `authors`: author string | Inserts commas after detected initials-like tokens, with a surname-particle exception using the module's `surname_particles` collection. |
| `separate_author_initials.add_separator(match)` *(nested)* | `match`: regular-expression match | Produces the replacement text for a detected initials-like author token. |
| `build_nested_groups(dataframe, keys_remaining, combine_func, rows_list=None)` | `dataframe`: source DataFrame; `keys_remaining`: ordered grouping columns; `combine_func`: callable applied to leaf groups; `rows_list`: optional result accumulator | Recursively groups on each key, handles null-key rows as their own branch, and accumulates `combine_func` results for non-empty leaf groups. |
